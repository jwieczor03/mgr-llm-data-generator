Jak oglądać

Możesz otworzyć ten plik bezpośrednio w przeglądarce. Alternatywnie z katalogu repozytorium: python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/ui, następnie adres http://127.0.0.1:8765/.

Nie ma backendu, zewnętrznych fontów ani wywołań modeli. Pobieranie udostępnia tylko opis demonstracji. Nie wykonano rzeczywistej walidacji danych.
