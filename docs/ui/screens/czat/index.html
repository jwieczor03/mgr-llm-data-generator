Raport demonstracyjny — żadnego sprawdzenia nie wykonano

Stan i liczby poniżej ilustrują proponowaną prezentację raportu, nie wynik działania generatora.

  • Kompletność: 880 z 880 rekordów; zakres podano w tabeli.
  • Importowalność: w scenariuszu potwierdzona próbnym importem PostgreSQL.
  • Relacje: w scenariuszu wszystkie obowiązujące powiązania poprawne.
  • Data dostawy: 3 naruszenia wśród 200 zamówień, np. zamówienie #42: dostawa 11.10.2026, zakup 12.10.2026.
  • Dodatnia cena: 0 naruszeń wśród 30 produktów.
  • Suma pozycji: 0 naruszeń wśród 200 zamówień; iloczyny pozycji zaokrąglane do 2 miejsc, przy połowie od zera, następnie sumowane.

Automatyczne rundy naprawcze: 3 / 3. Realizm danych: nieoceniany automatycznie. Model, czas, tokeny i koszt: brak pomiarów — to makieta.

Przycisk pobiera wyłącznie komentarz opisujący demonstrację, nie kompletny wynik SQL. Format eksportu raportu pozostaje otwarty w specyfikacji; ta makieta go nie ustala.
